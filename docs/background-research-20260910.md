# 后台研究与图文研报

## 使用

在金融研究智能体选择本机默认模型、自己的 API 或已授权本机 Codex；关闭「计划模式」后提交。页面立即显示后台任务链接。可切页、刷新或关闭浏览器，再从对话页右上角「研究任务」进入 `/#/research/tasks` 查看进度和历史。失败任务可使用原模型重新研究；这会创建新任务并重新取数/调用模型。

计划模式保留原有逐步确认流程，目前不进入后台任务队列。后台执行要求本机服务持续运行；关机、停止服务或重启后，未完成任务标记为「已中断」，由用户决定是否重试，避免自动重复扣费。

## 图文报告

网页报告包含数据要点、研究正文、行情及回撤曲线、同期价格比较、年度财务柱状图、来源和覆盖说明。悬停图表查看时间及数值，展开数据表可核对全部观测值。行情少于八个有效观测点时不画趋势；财务数据不足两年时不画年度柱状图。同行/基准比较只使用本次检索计划实际取到的标的，按共同交易日重新计算；没有可比数据时明确说明。

数据在取数阶段保存为快照，图表与指标用确定性公式计算，不解析模型输出中的数字。区间价格变动为末期/首期收盘价减一；回撤相对累计最高价；日频年化波动率为样本日收益标准差乘 √252。各源复权和报价口径保留，比较不是统一总回报或汇率调整后的收益。财务缺失值保留为空；未提供币种时明确显示原始报表单位，不猜币种。未取得 PE/PB 时不补造估值。

模型负责撰写与审查。模型失败仍保存已有图表、数据摘要及失败状态，不冒充完成的 AI 研报。本轮网页版本不新增 PDF 导出服务；原 Markdown 下载和浏览器打印功能保留。

## 实现与运行约束

- `POST /v1/research/jobs` 返回 202。请求包含 `request`、`source`（default/personal/codex）和 `client_id`；同一账户重复提交同一个 client_id 返回原任务。
- `GET /v1/research/jobs?offset=0` 分页返回任务摘要；`GET /v1/research/jobs/{id}` 返回任务与报告；`GET /v1/research/jobs/by-client/{client_id}` 用于提交响应中断后的恢复。
- 单个后台 worker，最多 20 个等待任务；单次任务上限 30 分钟。队列独立于 HTTP 响应和浏览器连接。请使用单进程启动；多 worker/多实例需要另行引入共享任务调度。
- 默认 SQL 配置中，任务保存在原数据库的新 `research_jobs` 表，图表保存在 `research_report_data` 表；不删除或改写旧表结构。显式选择 memory 存储的测试配置不提供重启后的持久化。
- 登录账户只可读取自己的任务；个人 API 在执行时从该账户的内存连接创建客户端，完成后关闭。数据库不保存密钥，也不在个人 API 失败时回退到系统模型。重启后个人 API 需重新连接。
- 匿名默认模型任务仅对本机回环地址开放。任务中心的账户隔离不代表整个旧版共享浏览器工作区已经完成多租户改造。

## 验证

本轮完整后端回归 383 项通过，前端研究流程与图表测试 17 项通过，TypeScript 检查和生产构建通过。

新增测试覆盖立即返回与断开后完成、账户隔离、重复提交去重、重启后结果与图表恢复、错误脱敏与队列继续执行、个人 API 独立客户端、完整研究流程及模型失败时图表保留、收益/回撤计算、共同日期对齐、缺失值与图表持久化。

独立测试页面已验证提交后切换量化页并刷新，后台任务完成后可回看图文报告。测试页面的样例明确标注测试数据，不调用外部模型。真实行情另行验证：AAPL/SPY 各 251 个观测值，生成收盘价、回撤与同期比较三张图；本次上游财务源返回空数据，报告显示缺失说明。没有以测试模型的成功结果替代对用户可用 API 的真实撰写验证。
