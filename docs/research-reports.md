# 后台研究与图文研报

金融研究智能体支持系统模型、用户自己的兼容 API，以及仅授权给指定本机账户的 Codex。关闭“计划模式”后提交问题，任务会进入本地后台队列；只要 FinAgent 服务仍在运行，关闭页面不会中断任务。可以从“研究任务”查看进度、重试与历史报告。

网页报告包含研究正文、关键指标、行情及回撤曲线、年度利润表、资产负债表、现金流量表、新闻线索、来源和数据缺口。图表只使用取数阶段保存的真实快照，不从模型文字中猜数字；缺失值保留为空，未取得估值倍数时不会补造。

个人 API Key 只暂存在当前服务进程内存，24 小时后或服务重启时失效，不写入数据库或浏览器存储。失败任务保留已经取得的数据和执行记录，不会自动切换到其他模型或自动重复扣费。

当前后台队列面向本地单进程运行：最多等待 20 个任务，单个任务上限 30 分钟。多进程或线上部署需要共享任务调度、持久化密钥管理和更完整的租户隔离。

## 数据与计算口径

- A 股行情和财报优先使用 AKShare 接入的公开数据，并以 Yahoo Finance 作为可用回退；其他市场主要使用 Yahoo Finance，可选 FMP。
- A 股公司资料使用东方财富公开接口；个股新闻使用新浪财经公开页面，保留日期、原文链接，并对最多三篇可访问正文提取有限节选。
- 区间收益、最大回撤和年化波动率由程序确定性计算。年化波动率采用日收益率样本标准差乘以 √252。
- 年度财务图至少需要两个年度。累计中报数据不与单季度数据合并。
- 全网搜索需要配置 Tavily 或 Exa；公共来源不可用时，报告必须明确数据缺口。

## 财务分析方法

财务指标由程序计算，作为证据同时送给撰写和复核阶段，并随报告保存。支持收入同比、净利率、资产负债率、ROA、ROE、经营现金流/净利润、总资产周转率和权益乘数；趋势图保留缺失值。ROA/ROE 使用连续年度期初期末平均余额；杜邦关系为净利率 × 资产周转率 × 权益乘数。ROE 为报表口径代理值，不自动声称为归母 ROE。

A 股整份报表优先选择 AKShare，其次 Yahoo，最后为已配置的 FMP；其他市场优先 Yahoo、其次 FMP。不再用一个供应商的收入和另一个供应商的利润拼接报表。跨表计算要求同来源、同币种、同期末日期；平均余额指标还检查资产=负债+权益（相对容差 0.1% 或绝对 1 个报表单位）。分母非正、冲突版本或必需字段缺失时不计算。行业适用性仍须人工复核，不能对银行和一般制造业机械套用同一评级。

取数时保留报告期末，披露日期仅在来源明确提供时保存；这尚不是完整的历史时点数据库。对已取得的多个标的，可比较同期净利率，但不自动认定为同行。不生成缺少预测现金流、折现率、终值增长率和股数依据的 DCF 目标价。

## 量化分析方法

- 信号只读取前一日及更早数据，在下一交易日收盘成交；当日收益归原持仓，新仓位从成交以后获得收益。买卖按换仓扣除成本，成本与收益复合计算。
- 指标预热期不计入绩效。主回测持仓期末按市值计价；夏普、Sortino 和单基准 Alpha 假定无风险利率为 0、每年 252 个交易日。Sortino 下行偏差以全部收益观测数为分母、最低可接受收益为 0；Calmar 为年化收益/最大回撤绝对值。
- 零波动、零下行偏差或零回撤时，对应比率不可用而非填零。盈利日占比是非零收益日中的正收益比例；换仓次数不是完整买卖笔数。
- 三折扩展训练/滚动留出：每折仅用训练段选择五组窗口参数（±10%、±20%、原参数），选参用共同预热起点、计入成本的累计收益；随后测试未参与本折选参的区间。每折从空仓开始，末日平仓并扣费；至少保留三个 20 日测试段。拼接各折净收益，而非平均各折累计收益。
- 这是内部留出验证。若先查看整个历史再决定策略或阈值，仍有选择偏差；尚未实施完整的试验登记、DSR 或 PBO，不宣称统计显著的 Alpha。
- 移除未经校准的百分制可信度，改为信号时序、留出结果、参数敏感度、成本和市场分组证据。兼容字段 score/reliability_score 返回 null。
- 非法收盘价、同日冲突价格或基准缺少标的交易日时显式报错。市场状态是事后描述；RSI 是简单窗口均值版本。未模拟停牌、涨跌停、整手、成交量和冲击成本，因此仍为研究回测。

方法与实现参考：[FinanceToolkit](https://github.com/JerBouma/FinanceToolkit)、[QuantStats](https://github.com/ranaroussi/quantstats)、[Qlib 的历史时点数据设计](https://qlib.readthedocs.io/en/stable/advanced/PIT.html)。本次采用现有 Python 数值实现并以手算样例验算，没有引入整套外部框架；参考项目的存在不等于本项目已经具备其全部能力。

## 运行与验证

任务接口为 `POST /v1/research/jobs`，历史与结果通过 `GET /v1/research/jobs` 读取。任务和图表分别保存在 `research_jobs` 与 `research_report_data` 表中，账户只能读取自己的任务。

本项目的自动测试覆盖账户隔离、后台任务恢复、个人 API 独立客户端、数据源路由、财报字段、新闻正文、图表生成、回测计算和失败语义。自动测试证明程序行为符合约定，不等同于供应商长期可用或投资结论正确。
