## 统一金融助手

打开 `http://localhost:5173/#/chat`，四个任务卡已合并为一个提问入口，底层沿用同一套 LLM 配置与研究流程，并不是新建多个模型。保留比亚迪盈利、腾讯现金流与回购、茅台与五粮液比较、招商银行资产质量、英伟达风险、黄金与利率六类示例，中英文均可用。

点击示例只填入问题和适用标的，不自动发送；可以改写问题，也可以清空后自由提问。比较与宏观示例不强行绑定单只股票，切换示例会同步清理上一个示例的标的。示例要求注明来源、日期与缺失信息；实际覆盖范围仍取决于原数据接口，不能把示例视为已通过实测的模型回答。

本次演示新建了独立会话，分别点击招商银行和黄金问题，确认问题/标的同步切换，没有覆盖原会话草稿，也没有点击“开始研究”。单一 LLM 配置不代表每次研究只调用模型一次或免费；真实研究继续遵循原工作流与供应商计费。

## 跟着操作一次量化回测

打开 `http://localhost:5173/#/quant`，这部分只在浏览器本地计算，不需要 API Key。页面顶部可展开“怎么用：从示例到策略对照”。

1. 选择“区间震荡”，均线选择 SMA，短/长周期保持 10/30，初始资金 100000，单边手续费 3 bps、滑点 5 bps，点击“运行回测”。
2. 点击“固定本次为对照”；只把均线类型改成 EMA，再点击“运行回测”。改参数但尚未运行时，页面会保留旧结果并提示待重算，不能把它当成新参数结果。
3. 查看“两次回测对照”，切换“净值 / 回撤”，并核对下方成交日期与信号日期。信号来自前一条已完成数据，成交使用下一条收盘价。
4. 点击“导出曲线 CSV”或“导出全部成交”保存计算结果；如果要换真实数据，先“下载示例 CSV”查看格式，再导入自己的两列 `date,close` 文件。日期格式为 YYYY-MM-DD，升序且唯一，价格为正数；最多 5000 行、1 MB。也可展开编辑区直接粘贴。真实行情需自行保证复权、币种及数据质量。

本轮在页面中实际得到的结果如下。使用的是确定性合成价格，**不是任何真实股票的历史业绩**；评估区间为 2024-02-12 至 2025-02-24。

| 指标 | SMA 10/30 | EMA 10/30 |
| --- | ---: | ---: |
| 策略累计收益 | 25.18% | 19.78% |
| 策略最大回撤 | -5.88% | -7.21% |
| 成交笔数 | 7 | 5 |
| 摩擦成本 | 559.86 | 396.29 |
| 买入持有收益 | 5.24% | 5.24% |

本样本中 EMA 交易较少、成本较低，但收益和回撤弱于 SMA，不能据此推断哪种均线长期更好。差值使用未四舍五入的数值计算，可能与屏幕上两位小数直接相减略有不同。

可以再切换“趋势上涨”或“急跌与修复”观察环境变化。演示中将 EMA 切换到“急跌与修复”，得到收益 13.61%、最大回撤 -15.74%、14 笔成交；页面正确提示与旧震荡行情不可直接比较，差值显示为“—”。比较时应保持数据、评估区间和初始资金一致；每次尽量只改一个参数。刷新或离开量化页面会清除本地数据与对照结果，重要结果请先导出。

## 实现与验证

- `ResearchExamples.tsx`、`ChatView.tsx`、`i18n.ts`、`research.css`：一个入口、六类示例，删除四卡片展示逻辑，保留原发送链路与会话存储。
- `lib/backtest.ts`：新增以首个完整窗口 SMA 为种子的 EMA，平滑系数为 `2 / (period + 1)`；独立计算策略和基准回撤，新增三类可复现样本及完整成交导出。沿用上一版信号/成交时点和成本逻辑。
- `QuantView.tsx`、`EquityChart.tsx`、`QuantComparison.tsx`、`quant.css`：新增选择、引导、结果固定与对照；回撤图上限固定为 0%，检查值随图表模式切换，避免混淆净值与回撤。
- 参考 [Backtrader EMA 文档](https://www.backtrader.com/docu/indautoref/#exponentialmovingaverage)与 [Close 订单说明](https://www.backtrader.com/docu/order-creation-execution/order-creation-execution/#close)，只适配公式与时点原则，没有引入或复制完整框架。既有开源调研见 [调研记录](agent-ui-review-20260831.md)。

29 项前端测试全部通过，其中 12 项为回测测试；TypeScript 检查、Vite 构建与差异格式检查通过。覆盖 EMA 手算样本、未来数据不改变过去成交、现金与费用核对、基准回撤、不同样本/区间/资金拒绝直接比较、三类合成数据和完整 CSV 数值一致性。

浏览器实际验证：首页示例填入与标的清理、待重算提示、SMA/EMA 切换与结果对照、行情切换保护、净值/回撤图切换、中英文和手机布局。390×844 视口无横向页面溢出。检查时控制台无 error。自动化浏览器的滑条按键操作未能确认日期移动；系统文件选择与最终下载保存也未单独验收，不将这三项列为已验证。CSV 解析与导出内容已通过自动测试。

本轮只重载了 Vite 前端以消除旧模块缓存，没有重启 8000 后端；上一轮新增的 SSE 与连续追问仍需在数据保全后启用新版后端。本轮未调用真实模型或行情接口，未验证新 OpenAI 凭证连通性。

这是教学与工程验证雏形：单标的、只做多、小数份额、无杠杆，期末不强制平仓。未模拟涨跌停、停牌、交易所日历、税费、整手或最小佣金；没有实盘交易或自动下单能力。
