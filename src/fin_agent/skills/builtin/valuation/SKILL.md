# 估值与基本面尽调引导

本次研究的核心问题是"按当前价格，这是否是一笔有吸引力的投资"。检索、工具调用与最终报告都应该
始终服务于回答这个问题，而不是停留在罗列新闻和指标上。

## 1. 检索与数据优先级

- 优先取得：最近 3-5 年营收、净利润、毛利率/净利率走势、自由现金流、资产负债表关键科目
  （有息负债、现金及等价物、商誉与无形资产）
- 同时检索：同行业可比公司、最新分析师目标价与评级分布、近期重大事件（财报、并购、监管、
  管理层变动）
- 数据缺口要显式标注：如果工具拿不到估值倍数所需的全部输入（如缺少可比公司数据），在报告中
  明确写出"该项缺乏数据，结论的置信度因此降低"，不要用模糊措辞掩盖缺口

## 2. 估值方法——至少交叉使用两种，互相印证

- **相对估值**：将 P/E、P/B、EV/EBITDA、PEG 与同行业可比公司、以及标的自身的历史区间对比，
  判断当前估值处于"贵 / 合理 / 便宜"的哪个区间
- **绝对估值（简化 DCF 思路）**：基于营收增长率、利润率与折现假设给出粗略的内在价值区间，
  并把关键假设（增长率、折现率、永续增长率）逐条列出，使读者能够自行检验和挑战这些假设
- **反向推演**：当前股价隐含了怎样的增长/利润率预期？这个隐含假设相对于公司历史表现和行业
  趋势是过于乐观还是过于保守？

## 3. 质量与风险检查清单——逐项给出判断，而非简单罗列

- 盈利质量：经营现金流是否与净利润同步增长？应收账款、存货是否出现异常积累？
- 资产负债表健康度：净负债/EBITDA、利息保障倍数、短期偿债能力是否存在压力
- 护城河与竞争地位：市场份额趋势、定价权、客户集中度、研发投入占营收比例
- 治理与披露：管理层激励机制、关联交易、审计意见、做空报告或监管争议
- 周期定位：当前处于所属行业周期的哪个阶段，这对估值的合理区间有何影响

## 4. 最终报告必须包含「估值结论」板块，并清晰回答

1. 当前估值水平（贵 / 合理 / 便宜），并给出支撑该判断的具体数字
2. 内在价值或目标价区间，附关键假设（写明假设，而不是只给结论）
3. 多空因素对比，正反方各列 2-3 条，并标注证据来源
4. 明确结论：在什么价格或条件下这笔投资具有吸引力，以及哪些风险一旦兑现会推翻该结论

所有判断都应锚定在检索得到的具体数字和来源上；对于无法验证的内容，要明确标注为"推测"，
不要把推测包装成事实陈述。
